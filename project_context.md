# Контекст проєкту

## Що це за проєкт

Це програмний 3D-рендерер (software renderer) для OBJ-моделі голови, який працює у реальному часі у вікні OpenCV.  
Рендер робиться на CPU: від читання геометрії до зафарбовування пікселів і тесту глибини.

## Що реалізовано

1. Зчитування 3D-моделі у форматі OBJ:
- вершини;
- нормалі;
- UV-координати;
- трикутні грані.

2. Малювання відрізків:
- реалізовано алгоритмом Брезенгема.

3. Зафарбовування трикутників:
- растеризація по барицентричних координатах.

4. 3D-перетворення через матриці:
- зсув;
- масштабування;
- обертання по осях.

5. Проєкції:
- перспективна;
- аксонометрична (ортографічна);
- перемикання в рантаймі.

6. Z-буфер:
- тест глибини на кожному пікселі;
- перевикористання буфера між кадрами.

7. Освітлення:
- модель Фонга;
- враховується diffuse + specular + ambient.

8. Текстурування:
- дифузна текстура;
- normal map;
- specular map;
- UV-семплінг з перспективно-коректною інтерполяцією.

## Як працює рендер-пайплайн (кадр)

1. Оновлюється час кадру, FPS та кут обертання моделі.  
2. Формуються матриці камери, об’єкта, проєкції, viewport.  
3. Очищується framebuffer і Z-буфер.  
4. Для кожного трикутника:
- вершини проходять через vertex stage;
- обчислюються/інтерполюються атрибути;
- виконується растеризація;
- на кожному пікселі рахується освітлення;
- проходить depth test;
- записується фінальний колір.
5. Кадр показується у вікні.

## Сцена і ресурси

- Основна геометрія: голова + частини очей (окремі OBJ).  
- Текстури: diffuse/normal/specular для кожної частини сцени.  
- Є HUD з інформацією про FPS і режим проєкції.

## Керування

- `P` перемикає тип проєкції.  
- `ESC` завершує програму.

## Основні оптимізації

- Попередні обчислення для трикутника, щоб зменшити роботу на піксель.  
- Перевикористання буферів кадру і глибини.  
- Паралельна обробка граней через OpenMP.

## Обмеження

- Розрахунок виконується на CPU, тому масштабування продуктивності обмежене.  
- Очікується триангуляція моделей.  
- Якість і вигляд залежать від наявності та коректності карт текстур.
